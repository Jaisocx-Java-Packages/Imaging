### Cropper One MaxSize

  |  🗓  **Updated**  |   🌾  Autumn 2026  | `Mon Sep  7 00:57:14 CEST 2026 UTC+02h 24h` |



  Dimensions for the maximal crop.
  The CMS Playmarket Theme image size may be set, too, any size, for example 420:860.
  The cropped image just keeps the relative dimensions for the cropped image.
  1:1 or 500:500 just mean the square max crop.
  if the original image was 2_350:2_000, the 1:1 cropped image gets size 2_000:2_000.
